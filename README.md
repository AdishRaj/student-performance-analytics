Student Performance Analytics System

Project Overview

This project analyzes student marks and attendance using Python, Pandas, and NumPy.

Features

- Student dataset loading
- Total marks, average, and percentage calculation
- Grade assignment
- Pass/fail analysis
- Subject-wise average marks
- Top-performing student identification

Technologies Used

- Python
- Pandas
- NumPy

Project Files

- "main.py" — Main program
- "functions.py" — Reusable functions
- "students.csv" — Sample student dataset

How to Run

1. Install Python.
2. Install dependencies using "python -m pip install pandas numpy".
3. Keep "main.py", "functions.py", and "students.csv" in the same folder.
4. Run "python main.py" in the terminal.

Learning Outcome

The project demonstrates Python functions, loops, conditions, CSV handling, and data analysis using Pandas and NumPy.# student-performance-analytics
